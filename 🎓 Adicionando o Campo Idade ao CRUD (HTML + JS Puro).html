10 Questões Objetivas com Gabarito

Questão 1: Declaração de Input no HTML

No modelo de código que utiliza referências diretas por ID (ex: nome.value), qual é a forma correta de declarar o campo de idade para que ele fique acessível como idade.value no script?

✅ Correto! (Gabarito: A) O atributo id="idade" cria o identificador global no DOM que permite ao JavaScript acessar o elemento diretamente pela variável idade, e o type="number" restringe para caracteres numéricos.

Questão 2: Inclusão no Cabeçalho da Tabela

No HTML original, temos: <tr><th>ID</th><th>Nome</th><th>E-mail</th><th>Ações</th></tr>. Qual alteração mantém a simetria com as linhas de dados?

✅ Correto! (Gabarito: A) Para que uma tabela mantenha suas colunas devidamente alinhadas, cada célula <td> criada no corpo deve possuir seu respectivo <th> no cabeçalho na mesma ordem.

Questão 3: Inclusão no Objeto do Aluno (Create)

Na função salvar(), na parte que cadastra um novo aluno (else), como incluímos a propriedade idade no array?

✅ Correto! (Gabarito: A) Cada aluno é um objeto estruturado em memória. Inserir a chave idade: idade.value garante que a propriedade fará parte do registro que será salvo no array.

Questão 4: Limpeza dos Campos após Salvar

O código original esvaziava os campos com nome.value = email.value = "";. Para esvaziar também o novo campo de idade, qual linha deve ser usada?

✅ Correto! (Gabarito: A) O encadeamento de atribuição nome.value = email.value = idade.value = ""; redefine o valor de todos os campos para uma string vazia em uma única linha limpa.

Questão 5: Operador de Fallback na Leitura

Na função listar(), utilizamos ${a.idade || "-"} para renderizar a idade. Por que usamos || em vez de ?? nesse caso?

✅ Correto! (Gabarito: A) O operador ?? (nullish coalescing) só trata null e undefined. Como o input vazio grava "", o ?? não ativaria o fallback. Já o || considera "" como falsy e exibe "-".

Questão 6: Carregamento no Modo de Edição

Na função editar(id), qual linha devemos acrescentar para que o valor da idade do aluno selecionado apareça no input para alteração?

✅ Correto! (Gabarito: A) Ao clicar em 'Editar', os inputs do formulário devem receber os valores atuais do objeto. A expressão a.idade || "" garante que, caso não haja idade gravada, o input fique vazio.

Questão 7: Atualização do Registro Existente (Update)

Quando idEditando não for nulo na função salvar(), como salvamos a nova idade no objeto encontrado?

✅ Correto! (Gabarito: A) A variável a armazena a referência do objeto localizado por alunos.find(). Atribuir a.idade = idade.value atualiza diretamente a propriedade daquele aluno no array.

Questão 8: Comportamento da Função persistir()

A função persistir() é declarada como: function persistir() { localStorage.setItem(CHAVE, JSON.stringify(alunos)); }. O que precisa ser alterado nela após incluir o campo idade?

✅ Correto! (Gabarito: A) A serialização JSON é universal: qualquer propriedade nova adicionada aos objetos em memória é automaticamente codificada em texto JSON e salva no LocalStorage sem alterar a função.

Questão 9: Exportação e Importação de Arquivos JSON

Ao clicar em '💾 Exportar' e gerar o download do arquivo alunos.json, os novos dados de idade estarão presentes?

✅ Correto! (Gabarito: A) Como a exportação e importação operam diretamente sobre o array de objetos e texto JSON puro via Blob e FileReader, qualquer novo atributo é preservado no arquivo baixado e importado.

Questão 10: Exclusão e Reset

O que acontece com as funções excluir(id) e resetar() após a inclusão do campo idade?

✅ Correto! (Gabarito: A) A função excluir() filtra o array pelo id do aluno (removendo o objeto completo com todas as suas propriedades), e resetar() apaga o registro inteiro do LocalStorage.
